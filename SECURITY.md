# Sicherheit

Sicherheitslücken bitte nicht als öffentliches Issue melden, sondern vertraulich über [„Report a vulnerability“](https://github.com/julianfaatz/click-to-call/security/advisories/new). Ich melde mich so schnell wie möglich.

Unterstützt wird jeweils die [neueste Version](https://github.com/julianfaatz/click-to-call/releases/latest).

---

Please report security vulnerabilities privately via [“Report a vulnerability”](https://github.com/julianfaatz/click-to-call/security/advisories/new), not as a public issue. Only the latest release is supported.
